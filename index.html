🟣 C盘整理侠

本地运行 · 文件不上传
⚠️ 使用前必读：
① 请用 电脑上的 Edge 或 Chrome 浏览器打开本页（手机打不开）。
② 弹出选择框后，推荐选你的用户文件夹：此电脑 → 本地磁盘 (C:) → Users → 选你用户名的那个文件夹（一个就够，下载/桌面/文档都在里面）。也可以分别添加「下载」「桌面」「视频」等文件夹，可以添加多个合并扫描。
③ 如果选「本地磁盘 (C:)」时提示 「无法打开此文件夹，因为其中含有系统文件」——这是浏览器的安全限制（任何网页都不许直接访问系统盘根目录），不是坏了：改选 Users 里的用户文件夹即可。
④ 删除不进回收站、无法恢复。系统目录（Windows、Program Files）会自动标红禁选。

📖 怎么分辨？（分类说明）

安装包（.exe / .msi / .apk）→ 软件装完就没用了，放心删；下次要装去官网重新下载
程序/软件本体 → 已装好的软件（多在 Program Files），删了软件就没了，别在这里删；卸载软件请去「设置 → 应用」
微信/QQ 数据 → 聊天图片视频最占C盘：电脑微信「设置 → 文件管理」改存到 D 盘并清理缓存
图片 / 视频 / 文档 → 你的个人文件，删前想想要不要备份，或迁移到 D 盘
压缩包（.zip / .rar / .7z）→ 解压过的一般可以删
AppData 软件数据 → 各软件的缓存，优先用软件自己的设置清理，不要整文件夹删
系统文件（Windows 文件夹里）→ 绝对不要动
